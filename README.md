# 🧠 MindPath AI

### AI-Powered Mental Health Screening & Therapy Guidance Mobile Application

**MindPath AI** is a Flutter-based mobile application developed as a Final Year Project (FYP). The primary goal of this application is to make mental health awareness and support more accessible by helping users understand their mental well-being through mental health screening and providing guidance about suitable therapies.

The application aims to create a user-friendly digital platform where individuals can explore their mental health concerns, identify possible symptoms of mental health disorders, and learn about available therapeutic approaches.

---

## 🎯 Project Objectives

- Provide accessible mental health screening.
- Help users identify potential symptoms associated with mental health disorders.
- Provide information and guidance about different mental health conditions.
- Suggest relevant therapy options based on screening results.
- Promote mental health awareness and early identification of concerns.
- Make mental health support more accessible through a mobile application.

## ✨ Key Features

- **Mental Health Screening:** Users can complete screening assessments to understand their mental well-being.
- **Disorder Awareness:** Provides information about different mental health disorders and their symptoms.
- **Therapy Guidance:** Helps users explore relevant therapeutic approaches based on their screening results.
- **User-Friendly Interface:** Simple and accessible mobile application design.
- **Firebase Integration:** Uses Firebase services for backend integration.
- **Cross-Platform Development:** Built with Flutter for mobile application development.

## 🚀 Getting Started

Follow these steps to run MindPath AI locally.

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git
- A Firebase project

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd mindpath_ai
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Configure Firebase**

Make sure your Firebase project is configured for the required platforms and the Firebase configuration files are properly set up.

**5. Run the application**

```bash
flutter run
```
